## Notes

- First release for Zig 0.17.0. The skill is renamed `zig-0.17` so it can be installed next to
  the 0.16 skill (`zig`, maintained on `release/0.16`). The gate targets the released 0.17.0.
- New gate `scripts/check-deprecated.py`: correct examples may not use a name the installed std
  marks deprecated (doc comment) or removed (`= @compileError`), nor a removed 0.17 construct
  from a short language table. Before the port it reported 196 uses.
- Content: a "Zig 0.17.0 Changes" section in SKILL.md; every reference ported (renames prepared
  by two subagents, each diff read and the non-mechanical rewrites compiled and run on 0.17.0);
  hand rewrites of std.zon.parse, Uri host lookup, @cImport, @Type, errdefer capture; Quick Fixes
  error texts captured from 0.17.0 by compiling each case.
- `zig-016-gotchas.md` became `zig-gotchas.md` with a 0.17.0 status per entry. "Fixed in 0.17.0"
  entries come from repro programs run on 0.16.0 and 0.17.0 (kept by the maintainer, outside
  this repository); "still true" entries from a std source diff or a probe on 0.17.0.
- Defects found that are also in v0.16.0-r3 (to fix in v0.16.0-r4): `toSubset` in comptime.md
  never compiled (shadowed name, runtime comparison), `@Type` taught although removed in 0.16,
  a leaking `allocPrint` in std-uri, names already deprecated in 0.16 (`mem.indexOf*`,
  `fs.path`, `tar.pipeToFileSystem`, ...).
- Ideas (not text) from kalpakprod/zig-skill (MIT): old/new probe pairs and a removed-spelling
  lint; implemented here independently, with the table generated from the std.
