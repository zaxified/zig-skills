## Notes

- First release for Zig 0.17.0. The skill is named `zig-0.17` so it can be installed next to
  the 0.16 skill (`zig`, maintained on `release/0.16`). The gate targets the released 0.17.0.
- New gate `scripts/check-deprecated.py`: correct examples may not use a name the installed std
  marks deprecated (doc comment) or removed (`= @compileError`), nor a removed construct from a
  short language table gated by Zig version. Before the port it reported 196 uses.
  `scripts/check-std-paths.py` now resolves file-wide aliases (`const ascii = std.ascii;`),
  honours shadowing and quoted names; that found 29 more broken paths (23 also in v0.16.0-r3).
- Content: a "Zig 0.17.0 Changes" section in SKILL.md (with a 0.16 → 0.17 migration checklist);
  every reference ported (renames prepared by two subagents, each diff read, non-mechanical
  rewrites compiled and run on 0.17.0); hand rewrites of std.zon.parse, Uri host lookup,
  @cImport, @Type, errdefer capture; Quick Fixes error texts captured by compiling each case.
- Build system and modes measured on 0.17.0 with probe projects: the configuration cache going
  stale on undeclared configure-time reads, the `zig build` flags that are rejected, optimize-mode
  spellings accepted by each CLI, incremental compilation per backend, maker build time, the test
  runner's allocator per mode.
- `zig-016-gotchas.md` became `zig-gotchas.md` with a 0.17.0 status per entry, re-checked on
  2026-10-10 by repro programs run on 0.17.0 (kept by the maintainer, outside this repository)
  or by std source diffs; entries added for traps 0.17 did not fix.
- Defects found that are also in v0.16.0-r3 are fixed there in v0.16.0-r4.
- Ideas (not text) from kalpakprod/zig-skill (MIT): old/new probe pairs and a removed-spelling
  lint; implemented here independently, with the table generated from the std.
