## Notes

- Maintenance release of the 0.16 skill (`zig`, branch `release/0.16`), from defects found while
  building the 0.17 skill (`zig-0.17`, `main`). The description now says it is for 0.16.x and
  points 0.17 projects to `zig-0.17`.
- Gates ported from `main`: `check-deprecated.py` (language rules gated by Zig version) and the
  alias-aware `check-std-paths.py`. Fixed with them: 68 uses of names 0.16.0 already deprecates,
  5 of `@Type` (removed in 0.16), 23 std paths that never existed (`std.c.c_int` and the other C
  integer types, `sockaddr_in`, `getcontext`, `flate.HuffmanEncoder`, `linux.MAP_FAILED`,
  `linux.empty_sigset`) and `linux.PROT.READ | WRITE` on a packed struct.
- Also fixed: `toSubset` in comptime.md never compiled (a parameter shadowing `Subset`, and a
  runtime comparison inside `inline for`) — the rewritten `Subset`/`toSubset` run on 0.16.0;
  std-uri leaked every `allocPrint` result; `flate.Compress.Huffman` cannot finish a stream in
  0.16.0 (`finish` is not `pub`) — documented instead of showing code that fails.
- Each rewritten block was compiled, and where it has behaviour run, on 0.16.0.
