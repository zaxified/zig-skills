## Notes

- Maintenance release of the 0.16 skill (`zig`, branch `release/0.16`), from defects found while
  building and auditing the 0.17 skill (`zig-0.17`, `main`). The description says it is for 0.16.x
  and points 0.17 projects to `zig-0.17`.
- Gates ported from `main`: `check-deprecated.py` (language rules gated by Zig version) and the
  alias-aware `check-std-paths.py`. Fixed with them: names 0.16.0 already deprecates, `@Type`
  (removed in 0.16), std paths that never existed, `linux.PROT` used as integer flags.
- `flate.Compress.Huffman` cannot finish a stream in 0.16.0 (`finish` is not `pub`) — documented
  instead of showing code that fails.
- Known limit of the gate: code fragments are not compiled (only standalone examples).
