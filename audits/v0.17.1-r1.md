## Notes

- Target moves from Zig 0.17.0 to 0.17.1. Measurements taken on 0.17.0 stay labelled so; they
  were kept after the 0.17.0 → 0.17.1 std diff was reviewed file by file.
- 0.17.0 bugs fixed in 0.17.1 are marked "0.17.0 only", with the workaround for projects still on
  0.17.0, and run on both versions where a reproducer exists: #37131 (`trunc nsw`), #37110
  (aarch64 error union with a 32-byte vector payload, under qemu), `std.debug.simple_panic`. The
  known-issues table now gives the 0.17.1 status of every row, plus the issues still open
  (#36256, #36969, #35724, #36444, #36986).
- New from the 0.17.0 backlog: #37321 (SVE predicates and syscalls), SmpAllocator internals (32 KiB
  size classes measured by page faults, slot-hop growth), a strRepeat/arrRepeat recipe without a
  quadratic comptime loop (66 s → 0.09 s of Sema at 40k copies), `Run.setEnvironmentVariable`
  freezing the configure-time environment, cached test runs ignoring the environment, forked
  children's faults arriving as SIGABRT, `DebugAllocator` leak detection in ReleaseFast.
- New from the 0.17.1 diff: `ff.Fe.eql`/`pow`, `checkAllAllocationFailures` refusing resizes,
  `can_spawn`/`can_replace`, `std.http` body semantics and `Reader.side`, `deployed_*` install
  bases, `zon.parse` fixes. ZLS 0.17.0 now exists, with build.zig regressions.
- Also in this release (unreleased since r5): wide `@bitCast` per-byte lowering (#36256),
  configure-time reads via `b.root`, stream-only `Io.Reader`, pointers into by-value parameters,
  `mem.find` over secrets, ecdsa `fromBytes`.
